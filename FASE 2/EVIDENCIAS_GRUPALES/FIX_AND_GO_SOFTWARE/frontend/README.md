# Prototipo web previo

Esta carpeta conserva el prototipo HTML/JavaScript existente antes de la app móvil. Es un visor básico de catálogo y solicitudes, con sesión solo en memoria y paginación compatible con la API. No incluye el flujo de materiales ni de pagos.

El cliente oficial y completo del MVP es `../mobile/`: React Native + Expo + TypeScript; también corre en navegador con `npm run web`. No desarrollar nuevas funcionalidades en este prototipo.
